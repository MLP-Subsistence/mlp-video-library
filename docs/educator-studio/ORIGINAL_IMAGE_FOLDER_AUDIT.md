# Verified Shutterstock originals by source video

The 25 Youth Africa video folders are backed by `src/lib/studio/verified-original-video-map.json` (Shutterstock IDs, not database asset IDs). A photo belongs to a folder when it was confidently identified in that source video's saved reference frame. Photos already selected in a Studio template remain visible in that video's folder too. Only assets tagged `source:high-quality-shutterstock` are eligible; screengrabs and unverified uploads never enter these folders.

The September 2026 audit compared 250 distinct originals from `C:\Users\uwish\Documents\MLP AFRICA PROJECTS\MLP AFRICA ASSETS\High Quality Shutterstock` with 430 saved frames from 25 videos. It used SIFT feature matches with geometric verification; the conservative automatic inclusion rule requires at least 20 inliers and over 55% of ratio-test matches geometrically consistent. That yielded 392 video/photo memberships (205 distinct originals) and included `1142898902` in introduction segment 4 and `1866006859` in segment 5. The older perceptual-hash matcher missed both. The 45 other originals remain available under **All verified originals**, not assigned to a source video without evidence.

To repeat the audit locally: run `npx tsx scripts/audit-original-folders.ts` from the repo, then run `python scripts/audit-originals-sift.py` with OpenCV and NumPy installed. Results and a proposed map are written to ignored `sync/`. Review candidate frames before updating the checked-in map; a low-confidence or unmatched frame is not evidence that the photo is absent from the video. Source originals are read only. The scripts do not update Studio assets, segments, or production data.
